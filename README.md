# AI Club Member & Event Platform

Welcome! 👋

This project helps Dallas College AI Club stay organized and have more fun.

## What this platform does

- Keeps track of club members
- Helps plan and manage events
- Stores important club information
- Shows helpful data to help the club grow

## Why this is useful

Running a club can be hard.  
This platform makes it easier by putting everything in one place.

## Simple idea

Think of this like a digital helper for your AI Club.  
It helps leaders and members work together better.
